Every row is in [`upjet.csv`](upjet.csv). Nothing here runs a Crossplane provider.

Each of our kinds is set against each Terraform resource Upjet serves for the same API resource. The **join** says how the two meet: `terraform` (the kind's `terraform:` in `hack/discokind/kinds.yaml`), `name` (the kind and the resource have the same name: `SQLUser`, `google_sql_user`) or `resource` (only the API resource). A kind with a `terraform` or `name` join is counted on those alone; its `resource` joins are listed as related and not counted.
